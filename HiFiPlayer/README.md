# Aster 音乐

Hi-Fi 开发分支播放器，0.2.2 最低固件 ABI 4.5。目前在 FAKE POD NANO PRO ESP32-S31 上使用，可选系统能力 `media-player`。

- 蓝牙接收：开启后手机连接 `Aster-S31 Audio`，显示手机提供的曲名、歌手、专辑，可播放/暂停/上下首和双向音量控制。
- 本地音乐：曲库读取 SD 卡 `music` 目录中的 WAV/FLAC 文件，最多显示 64 首，可翻页选择；也可播放随包附带的原创试听旋律。
- 蓝牙输出：点“耳机”搜索音箱/耳机，点设备连接；连接后本地音乐发送到所选设备。点“使用有线耳机”结束蓝牙输出。界面显示源格式与 SBC 输出格式，发送/接收互斥。
- 本地播放保留源采样率和位深（以服务协商结果为准）。蓝牙当前为 SBC，属于有损编码。
- 返回桌面保留后台音乐；切换模式会停止前一种源。当前不提供发送模式的耳机按键遥控、AAC、MP3 新媒体解码或完整音乐标签/封面解析。
- 曲库为目录当前层，不递归子目录。没有 `media-player` 后端的设备不能安装这个必需能力版本。

构建：在配置好 SDK 的终端运行 `aster build HiFiPlayer --target riscv --aot`，串口安装使用 `aster deploy PACKAGE --target riscv --port COM14 --run`，实际端口以设备识别结果为准。

`audio/demo.flac` 是本项目生成的 48 kHz/24-bit 双声道原创试听旋律，MIT 授权。

进度条支持整条触摸区域按下与拖动，拖动时预览目标时间，松手提交跳转；音乐自然结束后仍可拖到目标位置继续播放。

0.2.2 将进度行与播放控制分开，滑动明显超过点击阈值时取消按钮点击，防止拖动进度误触上下首。
