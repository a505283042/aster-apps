# Aster 音乐

Hi-Fi 播放器 0.3.3，最低固件 ABI 4.5。MP3 播放需要包含对应解码服务的固件。在 FAKE POD NANO PRO 上使用系统的 `media-player` 能力。蓝牙连接在系统下拉设置中管理，音量滑条位于播放页和曲库的标题栏下方。

- 手机接收：开启系统蓝牙后，手机连接 `Aster-S31 Audio`。播放页自动显示手机提供的曲名及歌手或专辑，可播放、暂停及切歌。
- 本地音乐：曲库读取 SD 卡 `music` 目录中的 MP3、WAV 和 FLAC。MP3 支持 32、44.1 及 48 kHz。曲库最多显示 64 首，可翻页选择，也可播放随包附带的原创试听旋律。
- 蓝牙输出：用系统蓝牙的“搜索设备”连接耳机或音箱。打开本地曲目时，音乐使用当前已连接的系统输出。播放页显示源格式与 SBC 输出格式。
- 播放页为歌词预留固定区域，当前显示“暂无歌词”。
- 本地播放保留源采样率和位深（以服务协商结果为准）。蓝牙当前为 SBC，属于有损编码。
- 返回桌面保留后台音乐；切换模式会停止前一种源。当前不提供发送模式的耳机按键遥控、AAC 或完整音乐标签／封面解析。
- 曲库为目录当前层，不递归子目录。没有 `media-player` 后端的设备不能安装这个必需能力版本。

构建：在配置好 SDK 的终端运行 `aster build HiFiPlayer --target riscv --aot`，串口安装使用 `aster deploy PACKAGE --target riscv --port COM14 --run`，实际端口以设备识别结果为准。

`audio/demo.flac` 是本项目生成的 48 kHz/24-bit 双声道原创试听旋律，MIT 授权。

进度条支持整条触摸区域按下与拖动，拖动时预览目标时间，松手提交跳转；音乐自然结束后仍可拖到目标位置继续播放。

0.2.2 将进度行与播放控制分开，滑动明显超过点击阈值时取消按钮点击，防止拖动进度误触上下首。
